# DiabetiDeck 🦆

Plugin experimental para mostrar la glucosa de Dexcom en la aplicación AJAZZ StreamDock.

## 🎯 Objetivo

Desarrollar un plugin propio que permita visualizar los datos de glucosa de forma cómoda desde el escritorio, utilizando una tecla del StreamDock.

## 🚧 Estado del proyecto

Actualmente, el proyecto se encuentra en fase inicial de desarrollo.

- [x] Crear la estructura básica del plugin.
- [x] Preparar la comunicación WebSocket inicial.
- [ ] Comprobar la compatibilidad con AJAZZ StreamDock.
- [ ] Conectar con una fuente de datos autorizada de Dexcom.
- [ ] Mostrar la glucosa real y su tendencia, si la integración lo permite.
- [ ] Añadir gestión de errores y pérdida de conexión.

## 🛠️ Tecnologías

- Node.js
- JavaScript
- WebSocket
- AJAZZ StreamDock

## 🔒 Privacidad y seguridad

- No publiques tokens, contraseñas ni credenciales de Dexcom.
- Las credenciales y los datos personales deben mantenerse fuera del repositorio.
- Este proyecto no es una aplicación médica oficial ni está afiliado a Dexcom.
- No utilices el plugin como única referencia para tomar decisiones sobre el tratamiento de la diabetes.

## 📌 Aviso

Proyecto personal y experimental. La conexión con Dexcom y la compatibilidad con StreamDock están pendientes de validación.
